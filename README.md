# Motion Watch - Система видеонаблюдения с детекцией движения

Масштабируемая система видеонаблюдения для IP-камер с детекцией движения и уведомлениями в Telegram.

## Возможности

- 📹 Поддержка множества IP-камер (RTSP, HTTP)
- 🔍 Детекция движения в реальном времени (оптимизировано для CPU)
- 📱 Уведомления в Telegram при обнаружении движения
- 💾 Непрерывная запись видео и аудио в сегменты
- 🎬 Создание видеоклипов из записей
- 🖥️ Веб-интерфейс для управления
- 🐳 Запуск через Docker Compose

## Быстрый старт

### 1. Клонирование и настройка

```bash
git clone https://github.com/yourusername/motion-watch.git
cd motion-watch
cp .env.example .env
```

### 2. Настройка переменных окружения

Отредактируйте файл `.env`:

```env
# Telegram бот
TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_CHAT_ID=your_chat_id

# Путь для записей
RECORDINGS_PATH=./recordings

# Пароль базы данных
DB_PASSWORD=your_secure_password

# Секретный ключ для JWT
SECRET_KEY=your-secret-key
```

### 3. Запуск

```bash
# Создать директорию для записей
mkdir -p recordings

# Запустить все сервисы
docker-compose up -d

# Посмотреть логи
docker-compose logs -f
```

### 4. Доступ к интерфейсу

- **Веб-интерфейс**: http://localhost:3000
- **API**: http://localhost:8000
- **API документация**: http://localhost:8000/docs

## Добавление камеры

1. Откройте веб-интерфейс
2. Нажмите "Добавить камеру"
3. Введите:
   - Название камеры
   - URL потока (например: `rtsp://user:pass@192.168.1.100:554/stream`)
   - Настройки детекции движения
4. Включите запись и детекцию

## Настройка Telegram бота

1. Создайте бота через [@BotFather](https://t.me/BotFather)
2. Получите токен бота
3. Узнайте ваш Chat ID (можно через [@userinfobot](https://t.me/userinfobot))
4. Добавьте токен и Chat ID в `.env`

## Конфигурация

### Переменные окружения

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `TELEGRAM_BOT_TOKEN` | Токен Telegram бота | - |
| `TELEGRAM_CHAT_ID` | ID чата для уведомлений | - |
| `RECORDINGS_PATH` | Путь для сохранения записей | `./recordings` |
| `DB_PASSWORD` | Пароль PostgreSQL | `motionwatch123` |
| `SECRET_KEY` | Секретный ключ для JWT | - |
| `SEGMENT_DURATION` | Длительность сегмента (сек) | `10` |

### Настройки детекции движения

- **Чувствительность**: порог изменения пикселей
- **Минимальная область**: минимальный размер области движения
- **Cooldown**: задержка между уведомлениями

## Оптимизация производительности

### Для максимального количества камер:

1. **Снизьте разрешение для детекции** - анализ проводится на уменьшенных кадрах
2. **Увеличьте интервал между анализами** - не каждый кадр анализируется
3. **Используйте hardware acceleration** для FFmpeg (если доступно)
4. **SSD для записей** - значительно ускоряет запись сегментов
